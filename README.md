# CreatorFlow

CreatorFlow is a simple content planning app designed to help creators organize, track, and manage their content ideas.

## Features
- Add content ideas
- Organize content workflow
- Track content status
- Simple and clean user interface

## Built With
- HTML
- CSS
- JavaScript
- Netlify Deployment

## Purpose
This project was created to explore web development, UI design, and building digital tools that help creators manage their workflow.
